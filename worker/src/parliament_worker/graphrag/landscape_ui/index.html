01 / 전체 흐름

데이터가 쌓이는 단계

수치는 서로 다른 단계의 저장 건수입니다. 전체 수집 대상의 완성률을 뜻하지 않습니다.

ⓘ

GraphRAG의 관계·요약·답변은 비공개 후보입니다. 마지막 MySQL 수치는 별도 법령 자료 경로이며 앞 단계와 이어지는 전환율이 아닙니다. 게시 판정은 앱 공개나 내용 검수 완료를 뜻하지 않습니다.
