# 공개·편집·정정 기준

대상은 정치에 관심 있는 시민이다. 동일 사건에서 짧은 사실 카드와 상세 근거를 제공한다. 모든 사실은 무료로 열람할 수 있다.

## 공개 조건

- 발표는 발표 주체의 주장·계획이라는 사실로 표시한다. 효과·시행·입법 완료를 추론하지 않는다.
- 법안 원안가결·수정가결·대안반영·철회·폐기를 구분한다. 원문 상태가 매핑되지 않으면 unknown이다.
- 표결방식이 비공개·무기명일 때 개인별 결과를 만들지 않는다. 원문 행 누락은 불참·기권이 아니다.
- 직접 인용은 원문 문장과 주변 문맥을 보존한다. AI 설명과 직접 인용의 표시는 구분한다.
- 인물 신원이 확정되지 않았거나 원문 날짜·이용 조건을 확인하지 못한 자료는 검수 대기 상태다.
- 상세 설명은 하루 최대3건 검수한다. 구조화 사실·메타데이터는 이 제한의 대상이 아니다.
- 원문·버전·출처·공개 시점·자료 범위가 없는 설명은 공개하지 않는다.
- 공식 자료라도 이용 조건을 항목마다 확인한다. 대통령 브리핑에서 발견된 공공누리4유형은 자동 수익화·요약 대상에서 제외한다. 원문별 별도 허락을 받은 경우 증빙을 남긴다.

## 정정

신고 접수 → 근거 확인 → 해당 버전 공개 보류 → 정정 이유와 새 버전 검수 → 새 버전 공개 → 구독자 묶음 정정 안내. 이전 버전과 그 근거를 삭제하거나 내용을 덮어쓰지 않는다. 모델·파서 오류 유형을 평가 표본에 추가한다.

## 추천과 개인정보

관심 대상 일치·새로운 변화·공개 시점으로 정렬한다. 정치적 분노나 체류시간만으로 최적화하지 않는다. 정파별 동일 건수를 맞추지 않으며 수집 범위를 공개한다. 관심 목록은 정치성향 추론·광고 판매에 사용하지 않는다. 익명 목록은 현재 브라우저에만 저장하고, 이메일 인증 후 서버에 저장한다.

## 출시 평가 양식

각 표본에 사건 ID·버전, 인물, 표결, 법안 상태, 날짜, 문장별 근거, 잘못된 연결, 직접 인용 일치, 이용 조건을 기록한다. 초기100건에서 인물·입장·표결·법안 상태의 중대한 오류가 없어야 한다. 결과는 아직 측정되지 않았다. 모델 결과를 사용하지 않은 메타데이터 카드 통과를 AI 평가 통과로 기록하지 않는다.
