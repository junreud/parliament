# 국회 공개 데이터 적재 준비

## 사용자 여정

- 운영자는 국회의원 고유 식별자를 기준으로 인물을 중복 없이 적재하고 싶다.
- 운영자는 국무총리, 장관, 차관 등 국회 밖 정부 공직자의 직위 이력을 함께 보존하고 싶다.
- 운영자는 공직 근거가 없는 증인, 참고인, 전문가 등 제3자를 `OTHER`로 보존하고 싶다.
- 운영자는 국회가 공개한 의원 SNS 링크를 플랫폼별 대표 계정으로 매핑하고 싶다.
- 운영자는 영상 원문이나 영상회의록 데이터가 적재되지 않는다는 것을 실행 전에 확인하고 싶다.
- 운영자는 API 키와 DB 쓰기 권한을 켜기 전에 API 계약, 페이지 수, 인물 변환 결과를 dry-run으로 검증하고 싶다.
- 운영자는 명시적으로 쓰기를 활성화하고 실행 확인을 보낸 경우에만 체크포인트 기반 적재를 시작하고 싶다.
- 운영자는 오늘 예정된 모든 API와 과거 실행 이력을 한 화면에서 확인하고, 정상 빈 결과와 재시도 최종 실패를 일반 실패와 구분하고 싶다.

## 범위 경계

- 열린국회정보에 등록된 공개 API 메타데이터를 기준으로 한다.
- 영상회의록, 발언영상, 시청각자료의 본문 및 메타데이터는 실행 대상에서 제외한다.
- 생중계와 영상 파일 분석은 수행하지 않는다.
- 영상 데이터 적재는 수행하지 않는다.
- API 키와 관리 키는 환경변수로만 받으며 로그나 보고서에 기록하지 않는다.
